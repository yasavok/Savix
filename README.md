### Возможности

- **7 протоколов**: VLESS, VMess, Trojan, Shadowsocks, Hysteria2, TUIC, WireGuard
- **Импорт**: по ссылке (vless://, vmess://, trojan://, ss://) и через подписки
- **Автоподключение** при запуске
- **Пинг-тест** — автоматический выбор лучшего сервера
- **Split tunneling** — настройка маршрутов обхода
- **Два режима**: системный туннель (TUN) и системный прокси
- **Маршрутизация**: DNS, TUN стек (Mixed/System/gVisor), MTU
- **Расширенные**: Multiplex (Mux), уровень логирования
- **Тёмная и светлая темы**, русский и английский язык
